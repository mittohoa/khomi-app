Mở Khomi trên web Không cần cài gì

Cài APK rồi thì đừng cài lại từ Play. Tệp APK ở đây ký bằng khoá riêng của nhà phát triển, còn bản trên Play do Google ký — hai chữ ký khác nhau nên Android không cho cập nhật chéo. Muốn chuyển sang bản Play thì phải gỡ bản APK trước, và sao lưu kho trước khi gỡ: mở app → Cài đặt → Sao lưu → Sao lưu ra tệp.

Bản Windows chưa ký số. Lần chạy đầu SmartScreen sẽ chặn — bấm More info rồi Run anyway. Giải nén nguyên thư mục và chạy khomi.exe từ trong đó; tách riêng tệp .exe ra là không chạy được. Nếu báo thiếu vcruntime140.dll, cài Microsoft Visual C++ Redistributable (x64). Đọc chữ trong ảnh, quét QR và khoá vân tay không có trên Windows — những thứ đó dùng thư viện chỉ chạy trên điện thoại.

Open Khomi on the web Nothing to install

Do not install the Play build over the APK. This APK is signed with the developer's own key and the Play build is signed by Google, so Android will not update one from the other. To switch, uninstall first — and export a backup before you do: Settings → Backup → Back up to a file.

The Windows build is not code-signed. SmartScreen will block the first run — choose More info, then Run anyway. Unzip the whole folder and start khomi.exe from inside it; the executable on its own will not run. If Windows reports a missing vcruntime140.dll, install the Microsoft Visual C++ Redistributable (x64). OCR, QR scanning and biometric lock are absent on Windows: those libraries are mobile-only.
