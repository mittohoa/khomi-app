Khomi

Ném mọi thứ vào. Tìm lại được.

Khomi giữ link, tin nhắn, ảnh, tệp và ghi chú bạn chia sẻ vào nó, tự đọc tiêu đề và xếp nhãn, rồi đưa lại cho bạn khi cần. Kho nằm trên máy bạn; đồng bộ đám mây là tuỳ chọn.

Dùng Khomi ở đâu

Windows 10/11

Bản đầy đủ, kho nằm trên máy bạn. Nhấn Ctrl+Shift+K từ bất kỳ đâu để ghi nhanh, hoặc kéo–thả link, ảnh, tệp vào cửa sổ.

Trình duyệt

Đăng nhập để đọc lại kho đã đồng bộ, tìm kiếm và mở lại thứ đã lưu. Chỉ đọc — thêm và sửa vẫn làm trên điện thoại.

Mở Khomi trên web Không cần cài gì

Bản Windows chưa ký số. Lần chạy đầu Windows SmartScreen sẽ chặn — bấm More info rồi Run anyway. Giải nén nguyên thư mục và chạy khomi.exe từ trong đó; tách riêng tệp .exe ra là không chạy được.

Nếu báo thiếu vcruntime140.dll, cài Microsoft Visual C++ Redistributable (x64). Đọc chữ trong ảnh, quét QR và khoá vân tay không có trên Windows — những thứ đó dùng thư viện chỉ chạy trên điện thoại.

Trang bắt buộc

  • Xoá tài khoản — cách xoá tài khoản và toàn bộ dữ liệu đám mây.

Open Khomi on the web Nothing to install

The Windows build is not code-signed. SmartScreen will block the first run — choose More info, then Run anyway. Unzip the whole folder and start khomi.exe from inside it; the executable on its own will not run.

If Windows reports a missing vcruntime140.dll, install the Microsoft Visual C++ Redistributable (x64). OCR, QR scanning and biometric lock are absent on Windows: those libraries are mobile-only.
